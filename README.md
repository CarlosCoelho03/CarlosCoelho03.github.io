# Ficheiros das Equipas

## Estrutura de ficheiros

```
team-pdfs/
├── index.html        ← app principal
└── pdfs/
    ├── equipa1.pdf   ← PDF da Equipa 1
    ├── equipa2.pdf   ← PDF da Equipa 2
    ├── equipa3.pdf   ← PDF da Equipa 3
    ├── equipa4.pdf   ← PDF da Equipa 4
    └── equipa5.pdf   ← PDF da Equipa 5
```

## Como publicar no GitHub Pages

1. Cria um repositório no GitHub chamado `team-pdfs` (ou outro nome)
2. Faz upload de todos os ficheiros mantendo a estrutura acima
3. Vai a Settings → Pages → Branch: main → Save
4. A app fica em: `https://CarlosCoelho03.github.io/team-pdfs/`
